# 📁 Mi portafolio · DAM

🇪🇸 Español · [🇬🇧 English below](#-my-portfolio--dam-english)

Soy titulado del ciclo **Desarrollo de Aplicaciones Multiplataforma (DAM)**, ya terminado, y ahora estoy cursando el **Curso de Especialización en Inteligencia Artificial y Big Data**. Este repositorio reúne mis proyectos y prácticas de los dos cursos, organizados para que cualquiera pueda ver qué he hecho y cómo.

## 🌿 Cómo está organizado

- `main` solo contiene este README, que hace de índice.
- **Cada proyecto vive en su propia rama**, con su código, recursos y un README propio (descripción, tecnologías, cómo ejecutarlo).
- Las ramas siguen el patrón `curso/asignatura/proyecto`, por ejemplo `dam1/programacion/mi-proyecto` o `dam2/android/mi-app`.
- Solo se publican actividades **completas**, que cumplen el enunciado.

## 🏷️ Autoría

Cada proyecto indica con una etiqueta cómo se ha hecho:

| Etiqueta | Significado |
|---|---|
| 🧑‍💻 Hecho por mí | Lo he desarrollado yo. |
| 🧑‍💻🛠️ Hecho por mí (IA solo para corregir errores) | Lo he desarrollado yo; he usado IA únicamente para ayudarme a depurar errores. |
| 🤖 Realizado con IA | Desarrollado con ayuda sustancial de IA. Está en una sección aparte. |

# 📁 My portfolio · DAM (English)

I have completed the **Cross-Platform Application Development (DAM)** vocational degree and am now taking the **Specialisation Course in Artificial Intelligence and Big Data**. This repository gathers my projects and coursework from both years, organised so anyone can see what I built and how.

## 🌿 How it is organised

- `main` only contains this README, which works as an index.
- **Every project lives in its own branch**, with its code, resources and its own README (description, technologies, how to run it).
- Branches follow the pattern `year/subject/project`, e.g. `dam1/programacion/my-project` or `dam2/android/my-app`.
- Only **complete** assignments that meet the brief are published.
