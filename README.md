# 📁 miportafolio

Repositorio personal donde organizo y guardo diferentes proyectos a lo largo del tiempo.

No es un portfolio público formal, sino un espacio privado para mantener mis prácticas, pruebas y proyectos bien estructurados y accesibles en el futuro.

---

## 🌿 Organización del repositorio

- Cada proyecto se desarrolla en **una rama independiente**.
- La rama `main` se mantiene como referencia general.
- Cada rama contiene su propio:
  - Código
  - Recursos
  - Archivos necesarios
  - Posible documentación específica

### Ejemplo de estructura de ramas
- proyecto-web
- api-node
- practica-sql
- app-react

De esta manera:
- No se mezclan proyectos entre sí.
- Puedo retomar cualquier trabajo meses después sin perder contexto.
- Mantengo un historial ordenado de mi evolución.

---

## 🎯 Objetivo

- Centralizar mis proyectos en un único repositorio.
- Practicar control de versiones con Git.
- Tener un histórico de aprendizaje.
- Probar nuevas tecnologías sin afectar otros trabajos.

---

Este repositorio está pensado principalmente para uso personal y como archivo de seguimiento de mi progreso.
Está en constante crecimiento.
